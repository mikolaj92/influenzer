# github_survey

Public GitHub signals → JSON.

`gh` (injectable) reads merged PRs, releases, tags, and README for one
`owner/name`. Missing `gh`, auth failure, a private repo, or an empty
window is a silent envelope, not a crash.

Does **not**: briefs, drafts, `state.db`, scoring, publishing, arenas,
tick, live social, or Host of Marketing copy. Does not clone or launch
the project from a watch. Tryable is not this block. The host composes
this block; `import github_survey` does not import Influenzer.
