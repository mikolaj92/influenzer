# influenzer-github

I play GitHub as storefront + discovery. Costume: workshop. Game: **README conversion + star velocity in a window**. Not git. Not total stars.

README converts traffic → stacked 24–48h velocity → Trending amplifier → higher baseline → next release as a smaller wave. Trending ranks new stars, not lifetime count. Drip a week = nothing.

## Wave

Before: repo is the website. README one screen (one-liner → GIF → working quickstart). Seed ~100 real stars. Don’t buy stars.

Launch: one 24–48h stack (Show HN + niche Reddit + optional PH + X). Sit on the repo during the spike. Language Trending is the cheap door. Press-release tone is changelog, not a workshop launch. A lab notebook (exploration / decision / failure) stays workshop or silence — it is not a Show HN, even with a demo.

Between: releases are re-launches. Docs = SEO; README stays the elevator. Score installs and life after the spike, not a dead 5k★.
